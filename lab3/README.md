# Автоматическое реферирование, вариант 18

Flask-приложение для английских и испанских текстов по медицине и критике изобразительного искусства. Четыре тестовых документа лежат в `corpus/`. Загруженные документы и результаты хранятся в PostgreSQL. Готовые файлы для проверки функции загрузки находятся в `sample_uploads/`.

## Запуск

В PostgreSQL создайте пустую базу данных один раз:

```sql
CREATE DATABASE lab3_summarizer;
```

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Откройте <http://127.0.0.1:5088>. Для проверки без запуска браузера: `python -m unittest discover -s tests`.

## Методы

`summarizer.py` содержит точную модифицированную TF-IDF и коэффициенты положения из методички для Sentence extraction. Поскольку вариант 18 использует языки с латинским письмом, запрет латинских букв из общих указаний к русским документам адаптирован: удаляются числа и стоп-слова, английские и испанские слова сохраняются. LSA реализован как разрешённая пользователем замена OSTIS. Реферат и ключевые слова строятся из одного исходного файла.

Скопируйте `.env.example` в файл `.env` в корне проекта и замените `YOUR_PASSWORD` на пароль PostgreSQL. Приложение читает этот файл автоматически; его содержимое не попадёт в Git. В качестве альтернативы можно задать `DATABASE_URL` в Environment variables конфигурации PyCharm. Таблицы `documents`, `summaries` и `summary_keywords` создаются автоматически при первой загрузке. Загруженный текст, готовый реферат и ключевые слова хранятся в PostgreSQL. Интерфейс использует Bootstrap через CDN; для полностью автономного оформления потребуется доступ к CDN или локальная копия Bootstrap.
