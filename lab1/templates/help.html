Help

This is an information retrieval (search) system built on the vector space model. Every document is converted into a vector of weighted terms (TF-IDF), and your search query is converted into a similar vector. Results are ranked by how close each document's vector is to your query's vector (cosine similarity) — the closer the angle between them, the higher the rank.

  • Go to the Search page and type an English query — a few keywords work better than full sentences (e.g. "vector space model cosine similarity").
  • Results are sorted from most to least relevant, with a snippet, the words from your query that were actually found in the document, and its date.
  • Require all query words narrows results to documents containing every word from your query, instead of allowing partial matches.
  • Date range filters results to documents added within the chosen From/To dates. Leave both blank to search all dates.
  • Click any result to open the full document and see its top-weighted index terms.

Open Add document. You can either:
  • paste text directly into the text box, or
  • upload a .pdf, .docx, or .txt file — its text is extracted automatically.
If you upload a file and leave the title blank, the file name is used as the title. If you leave the text box blank, the extracted file text is used. New documents are indexed immediately and become searchable right away.

Note: scanned PDFs that are just images of text (no selectable text layer) cannot be read automatically — use a text-based PDF or paste the text manually instead.

The Documents page lists everything in the collection. You can delete a document there, or click Rebuild index to recompute term weights for the whole collection (useful after deleting several documents, since term weights depend on the full collection).

The Quality metrics page measures how well the system ranks results, using the official ROMIP'2004 evaluation methodology, against a built-in set of test queries with known correct answers:
  • Precision — of everything the system returned, what share was actually relevant.
  • Recall — of everything that was actually relevant, what share the system found.
  • F-measure — a single score balancing precision and recall.
  • Average Precision / MAP — rewards putting relevant documents near the top of the results, averaged across all test queries.
  • Precision(5) / Precision(10) — accuracy of just the first 5 or 10 results (what a user would see on the first page).
  • R-Precision — precision measured at exactly as many results as there are relevant documents for that query.
  • 11-point Precision/Recall curve — the standard TREC chart showing the trade-off between precision and recall.
Hover over the ⓘ icon next to any metric for a short definition.

  • No results for my query — the system only matches whole words present in the collection; try simpler or different keywords, or turn off "Require all query words".
  • My uploaded file didn't work — check it's a .pdf, .docx or .txt file, and that the PDF has real selectable text (not just a scanned image).
  • Search results look outdated after deleting documents — click Rebuild index on the Documents page.
