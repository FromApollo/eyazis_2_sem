Crawl a folder

Point the crawler ("паук") at a directory on the server's filesystem (or a mounted LAN share) and it will walk every subfolder, extract text from any .txt, .pdf or .docx file it finds, and add it to the index. Files that were already indexed are compared by an MD5 hash of their contents: unchanged files are skipped, changed files are re-indexed, new files are added.

Absolute path on the server, e.g. /home/claude/documents or a mounted network path.
