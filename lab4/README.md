# Лабораторная работа 4 — вариант 3

Простое веб-приложение для прямого англо-немецкого перевода текстов по computer science и литературе. Стек: Python, Flask, PostgreSQL, SQLAlchemy, NLTK, Bootstrap.

## Возможности

- Ввод английского текста или загрузка `.txt` в UTF-8; выбор предметной области.
- Два готовых TXT-примера на главной странице: статья по computer science и литературное сочинение. Их можно подставить в форму одной кнопкой или скачать.
- Перевод с учетом слов и устойчивых терминов длиной до четырех слов. Исходные пробелы и знаки препинания сохраняются.
- Подсчет слов и переведенных слов; неизвестные слова остаются в исходном виде.
- Частотный список слов с немецкими переводами, Penn Treebank POS-тегами и русской расшифровкой тегов.
- Дерево составляющих выбранного предложения: NP, VP, PP, CLAUSE. Используется модель POS-теггера NLTK и грамматика из подхода предыдущей лабораторной работы №3.
- Автоматическое добавление новых словоформ в таблицу PostgreSQL, если их еще нет. Для морфологических форм используется существующий перевод, неизвестные переводы остаются пустыми. В интерфейсе можно добавлять, исправлять и удалять записи.
- Хранение результатов перевода, скачивание результата и частотного списка в TXT (UTF-8 с BOM), отдельная страница для печати.

## Запуск в PowerShell

1. Создайте базу PostgreSQL `lab4` (или свою) и укажите строку подключения. У пользователя БД должны быть права на создание таблиц:

   ```powershell
   $env:DATABASE_URL = 'postgresql+psycopg://postgres:postgres@localhost:5432/lab4'
   ```

   Если PostgreSQL установлен локально, базу можно создать командой `createdb -U postgres lab4` или через pgAdmin. Пароль в примере замените своим.

2. Установите зависимости и модель NLTK:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   python -m nltk.downloader -d .nltk_data averaged_perceptron_tagger_eng
   ```

3. Создайте таблицы и заполните начальный словарь:

   ```powershell
   flask --app app init-db
   flask --app app run
   ```

4. Откройте `http://127.0.0.1:5000/`.

Для запуска не на своем компьютере задайте также `SECRET_KEY` через переменную окружения. Команда `init-db` повторяемая: она добавляет отсутствующие начальные записи и заполняет пустые переводы из начального словаря, не перезаписывая непустые исправления.

## Проверка

```powershell
python -m unittest discover -s tests -v
```

Тесты используют временную SQLite-базу для изоляции; отдельно выполнена интеграционная проверка на PostgreSQL. Для повторной проверки с PostgreSQL используйте обычный интерфейс после `init-db`.

## Устройство

| Файл | Назначение |
|---|---|
| `app.py` | Маршруты Flask, работа с БД, экспорт и печать |
| `analysis.py` | Предложения, POS, дерево, частоты, перевод |
| `models.py` | Таблицы словаря и сохраненных переводов |
| `seed_data.py` | Начальные переводы двух предметных областей |
| `templates/`, `static/` | Интерфейс Bootstrap |
| `tests/` | Проверка полного пользовательского сценария |

Метод перевода намеренно простой и объяснимый. Он не перестраивает порядок слов и не согласует автоматически падеж, число и род немецких слов. Непереведенные слова видны в результатах и доступны для исправления в словаре.
