Automatic natural language processing is one of the most dynamically developing areas of modern computer science. It combines methods from linguistics, mathematical statistics and machine learning to solve a wide range of tasks related to text analysis and generation. Among these tasks one can highlight language identification of a document, keyword extraction, automatic summarization, machine translation, sentiment analysis and many others. Each of these tasks relies on statistical regularities inherent to natural language and on structural features of the vocabulary of a particular language.

Determining the language of a text is one of the basic preliminary tasks when building systems for automatic text processing. The correctness of subsequent processing modules depends directly on the correct solution of this task, whether it is a morphological analyzer, a syntactic parser or a machine translation module. An error at the language identification stage can lead to the entire subsequent processing pipeline being applied to a document using incorrect linguistic resources, which significantly reduces the quality of the final result.

There are several classical approaches to solving the problem of automatic language identification of a text. The simplest and at the same time fairly effective method is based on counting the frequencies of short sequences of characters, the so called N-grams. The idea of the method is that for each language it is possible to build a characteristic frequency profile of N-grams based on a sufficiently large training corpus of texts. Then a similar profile is built for the input document, which is compared with the profiles of known languages, and the language with the minimum distance between profiles is selected as the result.

Another common approach uses the frequent words of a language. In every natural language there is a relatively small set of words that occur significantly more often than the rest. This set usually includes function words such as prepositions, conjunctions, particles and pronouns. For example, in English the most frequent words include units such as the, of, and, to, in, a, is, that, it, for, was, on, are, as, with, his, they, at, be, this. The list of frequent words is fairly stable and changes little from text to text within the same language, which makes it a convenient feature for classification.

The method of short words is a modification of the frequent words method in which only words of small length, usually not exceeding five or six characters, are used as features. This approach allows the size of the feature vocabulary to be significantly reduced and speeds up the classification algorithm while maintaining high recognition accuracy, since short words are most often function words and highly frequent.

In recent years methods based on the use of artificial neural networks have gained considerable popularity. Neural network models are able to automatically extract features from training data without requiring manual construction of dictionaries of frequent words or tables of N-grams. The simplest architecture for solving the language identification problem is a multilayer perceptron, whose input is a numeric representation of the text, for example a vector of character N-gram frequencies, and whose output forms a probability distribution over language classes. Such a network is trained on a labeled corpus of texts using the backpropagation algorithm.

To evaluate the quality of a language identification system, metrics such as classification accuracy, recall, F-measure and the processing time of a single document are traditionally used. Accuracy allows one to estimate the proportion of correctly classified documents among all documents in the test collection, while processing time characterizes the practical applicability of the method in real time systems that process large volumes of textual data.

When building a test collection of documents for comparative analysis of methods it is important to ensure the representativeness of the sample. Texts should belong to different genres and styles, such as scientific articles, news reports, fiction and technical documentation. Such diversity allows a more objective assessment of the robustness of a method to variations in style and topic, which is especially important when moving from laboratory conditions to industrial deployment of the system.

An important stage in developing any automatic language identification system is preprocessing of the input text. At this stage the text is converted to lower case, punctuation marks and digits are removed, and, if necessary, stop words are removed as well. The quality of preprocessing directly affects the accuracy of building statistical profiles and, as a consequence, the final quality of classification.

The developed system should have a convenient user interface that allows users to upload documents, view classification results for each of the implemented methods and obtain summary statistics for the entire test collection. In addition, the system should support saving results to a file and their subsequent printing, which is necessary for generating report documentation based on the testing results.

Each new stage of technological development brought a substantial improvement in the quality of automatic natural language processing.
