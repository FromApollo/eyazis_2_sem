# Веб-приложение «Автоматическое распознавание языка текста» — вариант 10

Русский / Английский языки, документы в формате PDF.
Реализованы методы: **частотных слов**, **коротких слов**, **нейросетевой** (Python, Flask, Bootstrap 5).

## Структура проекта

```
lab2_web/
├── app.py                     # Flask-приложение (все маршруты)
├── langid_core/                # ядро системы определения языка
│   ├── preprocess.py            # предобработка текста, токенизация
│   ├── method_freq_words.py     # метод частотных слов
│   ├── method_short_words.py    # метод коротких слов
│   ├── method_neural.py         # нейросетевой метод (TF-IDF + MLPClassifier)
│   └── service.py               # сервисный слой: PDF, БД документов, статистика
├── scripts/
│   ├── build_profiles.py        # построение ПОЯ + обучение нейросети
│   └── seed_test_collection.py  # быстрое наполнение коллекции образцами
├── templates/                  # Jinja2-шаблоны (Bootstrap 5)
├── static/
│   ├── vendor/bootstrap/        # Bootstrap 5 (подключён локально, без CDN)
│   └── img/                     # генерируемые графики статистики
├── corpus/                     # обучающий набор текстов (ru/en, 20+ КБ каждый)
├── profiles/                   # построенные ПОЯ и нейросетевая модель (после сборки)
├── sample_test_docs/           # образцы PDF для тестовой коллекции + manifest.json
├── uploads/                    # загруженные пользователем PDF (тестовая коллекция)
├── data/                       # "БД" результатов (documents.json)
├── screenshots/                # скриншоты интерфейса (для отчёта)
└── requirements.txt
```

## Установка

```bash
pip install -r requirements.txt --break-system-packages

# Системная зависимость для экспорта PDF-отчёта (обычно уже есть в дистрибутиве):
# Debian/Ubuntu:
sudo apt-get install wkhtmltopdf
```

## Запуск

```bash
# 1. Построить поисковые образы языка (ПОЯ) и обучить нейросеть — один раз:
python3 scripts/build_profiles.py

# 2. (Необязательно) наполнить тестовую коллекцию образцами документов:
python3 scripts/seed_test_collection.py

# 3. Запустить веб-сервер:
python3 app.py
```

Приложение будет доступно по адресу **http://127.0.0.1:5050**.

## Возможности интерфейса

- **Главная** — загрузка PDF-документа, быстрая сводка по коллекции.
- **Тестовая коллекция** — список документов с активными ссылками на файлы,
  результатами по всем трём методам, экспортом в CSV/JSON.
- **Карточка документа** — извлечённый текст, подробные оценки каждого метода,
  возможность указать/изменить истинный язык документа.
- **Статистика** — таблица и графики точности/времени по методам, кнопки
  «Печать», «PDF-отчёт», «CSV», «JSON».
- **Справка** — пошаговая инструкция, FAQ, описание методов, тултипы (ℹ️),
  административная кнопка пересборки моделей.

## Восстановление после сброса

Если удалить `data/documents.json` и содержимое `uploads/`, коллекция
очистится. Чтобы вернуть тестовые документы, снова запустите
`python3 scripts/seed_test_collection.py`.
