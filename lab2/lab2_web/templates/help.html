Справка по работе с программой

Программа автоматически определяет, на каком языке — русском или английском — написан загруженный PDF-документ. Определение выполняется тремя независимыми методами: методом частотных слов, методом коротких слов и нейросетевым методом. Это позволяет сравнить методы между собой по точности и скорости работы.

  1. Откройте раздел «Главная».
  2. В форме «Загрузить документ» нажмите «Выберите файл» и укажите свой PDF-файл (одна страница А4).
  3. Если вы точно знаете, на каком языке написан документ — выберите его в списке «Истинный язык документа». Это не обязательно, но позволит программе посчитать точность.
  4. Нажмите кнопку «Загрузить и определить язык».
  5. Откроется страница с результатом: язык, определённый каждым из трёх методов, оценки уверенности и время обработки.
  6. Все загруженные документы сохраняются в разделе «Тестовая коллекция» — там же находится активная ссылка на сам файл.

  • Раздел «Статистика» показывает точность и среднее время каждого метода в виде таблицы и графиков (данные считаются по документам с указанным истинным языком).
  • Кнопка «🖨 Печать» открывает стандартное окно печати браузера для текущей страницы.
  • Кнопка «⬇ PDF-отчёт» формирует и скачивает полный отчёт по всей тестовой коллекции в формате PDF — удобно для сохранения в файл или последующей печати.
  • Кнопки «⬇ CSV» и «⬇ JSON» сохраняют результаты в файл для дальнейшей обработки в Excel или других программах.

Метод частотных слов. Для каждого языка заранее строится список самых часто встречающихся слов (например, «и», «в», «не» для русского; «the», «of», «and» для английского). Текст документа сравнивается с этими списками — побеждает язык, чьи частотные слова чаще встречаются в документе.

Метод коротких слов. То же самое, но используются только короткие слова (до 5 букв), которые обычно являются служебными и наиболее характерными для языка. Это делает метод устойчивее на очень коротких документах.

Нейросетевой метод. Текст представляется в виде числового вектора (частоты сочетаний букв), который подаётся на вход обученной нейронной сети (многослойный персептрон). Сеть заранее обучена отличать русский текст от английского на большом наборе примеров.

Почему кнопка загрузки неактивна? — значит, ещё не построены модели (профили языков). Нажмите кнопку «Построить профили языков» ниже на этой странице.

Можно ли загрузить документ на другом языке? — система обучена различать только русский и английский языки (согласно варианту задания №10). Другие языки будут ошибочно отнесены к одному из этих двух.

Что если методы дали разные ответы? — это нормально для очень коротких или нетипичных текстов. Откройте карточку документа, чтобы увидеть детальные оценки уверенности каждого метода.

Как удалить документ из коллекции? — на странице «Тестовая коллекция» нажмите кнопку «✕» в соответствующей строке.
